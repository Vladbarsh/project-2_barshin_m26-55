# Примитивная база данных

Баршин Владислав, М26-55. Домашнее задание №2 по Python.

Консольная программа для работы с таблицами. Данные хранятся в JSON-файлах.

Нужны Python 3.12 и uv. Установка и запуск из папки проекта:

```console
uv sync
uv run database
```

Команда `uv run project` запускает ту же программу.
